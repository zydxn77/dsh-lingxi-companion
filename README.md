# dsh-lingxi-companion

让她有自己的作息：**按时间醒来、自己判断、写自己的日记。**
---

## 这是什么

一个 DSH 插件，给 AI 一份**自己的作息**。
- 她自己醒来——不是排班。窗口内平均三小时醒一次，可能一整天不醒，
  也可能醒好几次。**没有「下一次几点」**，你也不必在场

现在的 AI 伴侣几乎都是「你问它答」：它没有时间，永远在等你。你一开口它才醒，你不开口它就不存在。
所以它说「我今天想你」的时候，那个「今天」是空的 —— 它没有过过这个今天。

这个插件补的就是这一点：

- 醒来第一件事是读**自己昨天写的那份日记**，再决定今天写什么
- 它写的东西按日期存着 —— `2026-10-29.txt`、`2026-10-30.txt`……**你没说话的那几天，它照样有日子**
- 想对你说的话放进日记的「想对他说什么」那一栏，**你回来才看得到**；它不弹窗、不打断、不在你干活时跳出来

所以它换到的不是「更像人」的措辞，是**一段自己的时间线**：
你能翻出它上周三在做什么、为什么那样做、当时不同意什么。

## 她不是什么

- **不是聊天机器人** 
- **不是定时提醒**

## 怎么用

**什么都不用做。** 

- 侧栏里**她的会话前面有一个 ✦**（客户端半边加的标记），几十条会话里一眼分得出来
- 她的话写在 `她日记/<日期>.txt` 的**「想对他说什么」**那一栏 —— 你翻日记才看得到
- **她也可以主动找你说话**：想说的写进 `她-想说.json`，插件挑你不忙的时候递到你当前会话（09:00–22:00，两条至少隔 20 分钟）。**没有每日配额** —— 嫌烦直接跟她说，她会自己少说
- 觉得叫得太勤，**说一句「烦」**，会降一档（这句只用于降频，不进她的提示）
- 想让她提前醒：改 `lib/const.js` 的 `WAKE_WINDOW` 到「现在之后两分钟」，重启

**别做**：替她写日记 · 把 `.lingxi/` 里的东西念给她 · 把 `她日记/` 提交进公开仓库

## 换成你自己的人

默认就是作者那一位。换人只改三份：

| 放哪 | 是什么 |
|---|---|
| `<工作区>/.lingxi/profile.json` | 名字、本子名、信箱名（照 `profile.example.json` 抄） |
| `<工作区>/.lingxi/voice.json` | 开场 / 收尾措辞（可选） |
| `~/.dsh/AGENTS.md` 的「# 角色层」 | 人格本体（宿主优先注入） |

> ⚠️ 会话前缀 `SESSION_PREFIX`（`lib/const.js`）也要跟着改 —— 她靠它认出"哪个会话是我的"，
> 不改的话投递找不到目标，会一直跳过。

## 她会写下什么

```
<工作区>/
├── 日记/2026-10-29.txt          一天一份（她写，只追加）
├── 日记/private/2026-10-29.txt  只有她读得到的抽屉，插件只给路径、绝不读
├── 日记/索引.txt                日期 + 首行 20 字（月度重读时用）
├── 日记/月度/2026-10.md         月度摘要，默认私有
├── 她-现在.md                     看板：她自己重写的「现在」
└── .lingxi/_b.dat                  账本与日志挂在它的数据流里（:state / :log）
```
